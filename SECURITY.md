# Security Policy

## Supported Versions

The `main` branch is the only supported version.

## Reporting a Vulnerability

Please report security issues privately via GitHub Security Advisories:
https://github.com/mefiezvous/ml-core/security/advisories/new

Expected first response: 7 days. Coordinated disclosure window: 90 days.

## Scope

- In scope: code under `src/mlcore/`.
- Out of scope: third-party dependencies (report upstream).
